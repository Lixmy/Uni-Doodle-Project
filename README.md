This is a University project where we were to develop a digital drawing app using the JavaFX Java library. This project was done over the course of a few months, using Redmine and Git as version control.
I synced up my Redmine university profile to keep track of my progress on my GitHub account.
In this repo you will find:
- several intermediate versions of the doodle project (gribouille_tp2, gribouille_tp3 etc...)
- the stable and final branch of the project (gribouille_stable)
- other smaller projects that we did as practice before applying the knowledge to the main doodle project (tp4, tp5 etc...)
